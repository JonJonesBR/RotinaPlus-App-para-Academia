# Security Policy

## Supported versions

This public portfolio repository is maintained on the default branch.

## Reporting a vulnerability

If you find a vulnerability, exposed credential, or unsafe configuration, open a private contact channel with the repository owner before creating a public issue.

## Secrets policy

Do not commit API keys, tokens, passwords, keystores, service accounts, .env files, or production URLs. Use .env.example for placeholders and keep real values only in local environment variables or deployment secrets.
